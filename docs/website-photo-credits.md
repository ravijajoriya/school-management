Deliberately left for the school's own photos:

- **Principal photo** (About page): a stock face must not stand in for a real person.
- **Gallery → Campus**: stock photos of another building would misrepresent the school.
- Hero slide and facility photos: already uploaded by the school.

To replace a stand-in: Admin → Website → Media Library → upload the school's photo, pick it on the page (Website Pages), publish,
then set the stand-in to not public or delete it.
